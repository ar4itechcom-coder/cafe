# عنبر — نظام مطعم Full Stack

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:
   npm install
   npm start
4. افتح:
   http://localhost:3000
5. لوحة التحكم:
   http://localhost:3000/admin

## بيانات المدير الافتراضية
البريد: admin@anbar.local
كلمة المرور: Admin@12345

غيّرها قبل أي استخدام حقيقي عن طريق متغيرات البيئة:
ADMIN_EMAIL
ADMIN_PASSWORD
SESSION_SECRET

## ما تم تنفيذه
- Front-end عربي RTL متجاوب.
- منتجات وأسعار وصور.
- سلة مشتريات.
- حساب إجمالي الطلب.
- رسوم توصيل 1 د.ك، ومجانًا من 10 د.ك.
- الدفع عند الاستلام فقط.
- رقم فريد لكل طلب.
- إنشاء حساب وتسجيل دخول.
- جلسات حسابات مشفرة بكلمات مرور bcrypt.
- استرجاع كلمة السر: endpoint تجريبي، ويحتاج مزود بريد للإرسال الفعلي.
- صفحة طلباتي للمستخدم.
- قاعدة بيانات SQLite.
- لوحة تحكم للمدير.
- إحصائيات الطلبات والمبيعات.
- تغيير حالة الطلب.
- إضافة وتعديل وإخفاء المنتجات.

## قبل النشر العام
- استخدام HTTPS.
- تغيير بيانات المدير وSESSION_SECRET.
- إضافة CSRF/rate limiting وvalidation أقوى.
- ربط خدمة بريد حقيقية لاسترجاع كلمة السر.
- إعداد نسخة احتياطية لقاعدة البيانات.
- إضافة WhatsApp/SMS أو خدمة إشعارات إذا رغبت.
- إضافة نظام مناطق التوصيل إذا كان لديك مناطق وأسعار مختلفة.
